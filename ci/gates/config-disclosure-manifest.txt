# admin.config.show disclosure manifest (#162).
# decision<TAB>path<TAB>rationale
#
# THE SURFACE IS A UNION, which is why this file exists rather than a comment
# pointing at one artifact: docs/configuration.md §4/§5 (core, lake), the
# section parsers (transport.rs, audit_cfg.rs, principal.rs,
# maknae-vault/config.rs), and boot.rs's SectionSpec list.
#
# Four decisions, and 'mask' is the common and correct one:
#   disclose  the value ships in the clear
#   mask      the value is withheld; the KEY still appears (<value set>)
#   always    ships BY CONSTRUCTION on a non-allowlist surface (StatusView,
#             returned whole by admin.status). Still a recorded decision, and
#             a new field on that struct still fails the gate until one exists.
#   omit      the key does not appear at all — its EXISTENCE is the disclosure
#
# 'disclose' and 'omit' rows must match DISCLOSABLE/SUPPRESSED in document.rs
# exactly, both directions. 'mask' rows are the default and appear in neither.
disclose	core.deployment_id	baked into every plane leaf's URI SAN; any peer completing a handshake already has it
disclose	core.schema_version	deployment shape; carried verbatim, named by no parser (docs/configuration.md §4)
disclose	core.identity.instance_id	deployment shape (§4)
disclose	core.identity.name	deployment shape (§4)
disclose	core.identity.domain	deployment shape (§4)
disclose	core.identity.urn_root	deployment shape (§4)
disclose	vault.addr	WHERE vault is, never a credential
disclose	vault.approle_mount	mount name, never a credential
disclose	vault.pki_int_mount	mount name, never a credential
disclose	vault.deployment_id	the supported fallback spelling of core.deployment_id
disclose	audit.jsonl_path	the log the operator is trying to find
disclose	principal.name	readable by any local process via getpwuid
disclose	principal.uid	readable by any local process via getpwuid
disclose	principal.home	readable by any local process via getpwuid
disclose	provider.name	the operator's label for the one registered model provider (#243)
disclose	provider.endpoint	where the loop's content goes; the point of registering it
disclose	provider.model	the model identifier sent on every request
omit	provider.key_vault_path	the secret store's layout; not the key, and not the grant's business (ADR-0023 d3)
disclose	transport.socket_path	the socket the daemon is listening on
disclose	transport.max_connections	transport shape
disclose	transport.frame_max_bytes	transport shape
disclose	transport.handshake_timeout_ms	transport shape
disclose	transport.read_timeout_ms	transport shape
omit	vault.insecure_plaintext_secret_path	PRESENCE says this host keeps an AppRole SecretID in plaintext on disk
omit	core.handling	PRESENCE says this deployment configured an above-baseline classification ceiling (prefix)
omit	audit.au3_1	deployer-authored sub-key NAMES with no schema; a path allowlist cannot classify what it cannot enumerate (prefix)
mask	audit.siem	an offload endpoint with no schema, no validator and no consumer; common shapes embed a credential in the URL
omit	lake	registered but INERT (docs/configuration.md §5): keys and shape unvalidated, deployer-authored, unenumerable — same condition as audit.au3_1 (prefix)
always	status.version	the daemon's own version; an operator debugging needs it and any peer that handshook knows the protocol already
always	status.protocol_version	every peer that completed a handshake already has it
always	status.listener	the socket the caller is already connected to
always	status.authz_backend	which PDP produced a verdict; the point of the field
always	status.classification_policy	which classification SYSTEM ranked a ceiling (ADR-0022); a name from the build's registry, never a level or a marking
always	binding.role	the policy-file role token an operator would grep for
always	binding.members	the identities bound to it; the answer admin.subject.list exists to give
always	whoami.peer_plane_uri_san	the caller's own verified plane identity; it is who they already are
always	whoami.peer_uid	the caller's own uid, which they can read with getuid()
